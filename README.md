# KUB Software Application Overview

This project provides built-in utilities designed for 64-bit Windows environments, featuring executable scripts and compiled tools.

---

## Technical Specifications

| Property | Value |
| :--- | :--- |
| **Target Architecture** | x86-64 / AMD64 |
| **File Format** | Portable Executable (PE32+) / Scripting |
| **Environment** | Microsoft Windows (64-bit) |
| **Toolchain** | Python / CustomTkinter / MSVC Linker |

---

## Software Packages Included

* **KUB_Sakura_Shell.exe**: Custom utility interface designed for system options and shutdown management.
* **Sıfır-Lock Utility.exe**: Local network utility and port checking manager.

---

## Execution Requirements & Setup

1. **Operating System**: Windows 7 / 8 / 10 / 11 (64-bit systems).
2. **Launch**: Execute the binaries directly from the `KUB_software` directory or launch via PowerShell:
   ```cmd
   .\KUB_software\KUB_Sakura_Shell.exe
